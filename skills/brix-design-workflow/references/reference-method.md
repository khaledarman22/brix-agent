# One reference for the whole website

Reuse the project's existing selected reference. Otherwise inspect real references until one sufficiently complete site matches the brief, select it autonomously, and proceed directly to DNA and execution. No approval board or fixed candidate quota is required. A user's explicit selection wins.

Use only screenshots, pages and crops from that source. Do not borrow separate headers, cards, typography or footers from different sites. For missing sections adapt the selected source's established rules to the brief; label inference and never claim unseen content was inspected. Reference screenshots belong on a Figma References board, not as finished UI or unlicensed product imagery.

Save root `reference-selection.json` with `reference_policy: "single-source"`, `primary: {"id": "stable-id", "source": "actual URL"}`, `secondary: []`, and `applied_reference_ids: ["stable-id"]`. Record rationale and inspected pages/screenshots. Same reference ID must appear in both DNA files as `meta.design_reference_id`.
