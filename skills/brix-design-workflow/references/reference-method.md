# Section-level reference method

Use this when creating a new screen, section, or reusable pattern that the existing project does not already cover.

1. List the requested sections and repeated parts. Associate each with its purpose and useful search terms: e.g. “portfolio project mosaic”, “service pricing comparison”, or “RTL account recovery”.
2. Research real products and visual sources appropriate to the task. Sources may include live sites, Awwwards, One Page Love, Land-book, Behance, Dribbble, Pinterest, or user-provided screenshots. Access through available authorized tools; do not claim access to a gated library that is not connected.
3. Open and inspect the actual visuals. Track source URL, what was observed, and the section it supports. A search snippet or image title does not establish a layout. If a source cannot be inspected, disclose the gap and use another.
4. Put useful references on a board scoped to the section, such as `References – Home – Hero` or `References – Components – Project card`. Use short letter/number labels. The board should support a decision, not become a quota of screenshots.
5. Choose what to take: one reference might supply the section layout, another the card treatment, another the image framing. Mark/crop the exact regions at useful resolution. Respect the user's selections and annotations.
6. Adapt to the project's own content, type scale, palette, spacing, icon family, and language. Preserve usability; do not reproduce decorative details that undermine readability or the task.
7. Extract reusable patterns into components before assembling their instances. If a required detail has neither an established project pattern nor a visible reference, find a focused reference for it instead of inventing an unrelated style.
8. Inspect the resulting section screenshot against the selected visual structure and the current identity. Revise the design, not unrelated approved areas.

For imagery, keep reference provenance separate from product asset provenance. Gallery images can inform composition but do not automatically grant reuse rights. A generated image or permitted stock photo should match the intended subject, crop, lighting, and palette; inspect it inside the design.

If the user supplies or selects a sufficient reference, work from it directly. If they explicitly waive references, honor that and record the chosen direction without fabricating research.
