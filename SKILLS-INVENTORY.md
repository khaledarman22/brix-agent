## Retention choices

The local frontend-design skill is retained because its actual content teaches art direction, typography, composition and content decisions. Impeccable, Interface Design, Refactoring UI, UI UX Pro Max, UserInterface.wiki and Make Interfaces Feel Better retain useful visual/interaction guidance even where they include code examples. They do not authorize implementation. The project agent uses their design principles only.

Swiss, Nothing, Scandinavian and Material remain optional design languages; none overrides a chosen identity. Emil retains animation vocabulary, Apple interaction principles, design polish and read-only motion proposals. Bencium retains controlled/innovative visual design, audit, relationship design and typography. All 111 Designer Collection skills concern design practice, including design research/operations, and remain.

Native editable Figma output still requires an actual connected writer and relevant host skills. No retained skill is represented as a Figma connection.
